## Welcome to Harmoniq 2.0: The Next Generation of Desktop Audio

Harmoniq 2.0 represents a monumental evolution in desktop music listening. Built from the ground up for Windows 10 and 11, Harmoniq combines professional-grade digital signal processing, an obsidian-and-violet audiophile user experience, local-first intelligence, and seamless Windows native integration.

---

## 🌟 What's New in Harmoniq 2.0

### 1. Professional Audio Experience Studio
- **Dual-Deck Web Audio Playback Engine:** Seamless, click-free gapless transitions and crossfading with independent source decoders.
- **Parametric EQ Studio:** Interactive frequency response visualizer supporting up to 12 fully configurable parametric bands (peaking, low-shelf, high-shelf, notch, band-pass), AutoEQ preset importing, and real-time filter auditioning.
- **10-Band ISO Graphic Equalizer:** Precision ISO standard center frequencies with calibrated preamp gain and tone controls.
- **Mid-Side Stereo Width Processing:** Discrete spatial soundstage expansion without phase distortion.
- **Smooth Parameter Automation:** Zero-zipper, click-free DSP transitions powered by logarithmic time constants.
- **Anti-Clipping Peak Limiter Protection:** High-speed peak control ensuring transparent protection against digital clipping.

### 2. Intelligent Audio Personalization & Profiles
- **Unified Sound Profiles:** Curated acoustic tunings including Reference Flat, Tube Warmth, Open Stage Clarity, and Late Night.
- **Per-Track EQ Memory:** Automatic recall of tailored equalizer and volume settings on a per-song basis.
- **Per-Device Audio Profiles:** Device-aware output configurations with dedicated volume persistence for headphones, external DACs, and speakers.
- **Audio Quality Transparency:** Truthful, real-time diagnostic stream inspection detailing actual codecs, bit depths, sample rates, resampling diagnosis, and output driver modes.

### 3. AI Companion & Conversational Music Assistant
- **Pulse Orb Reactive Visualizer:** Real-time audio-frequency reactive visual orb reflecting listening energy and acoustic mood.
- **Conversational Playlist Assistant:** Generate intelligent, mood-based playlists using natural language prompts.
- **Natural Language Library Discovery:** Instant querying and intelligent curation across your entire music collection.

### 4. Windows Native Desktop Integration
- **Windows File Associations:** Native shell registration for `.flac`, `.mp3`, `.wav`, `.m4a`, `.alac`, and `.ogg` files with custom Harmoniq iconography.
- **Taskbar Thumbnail Toolbar:** Control playback directly from the Windows taskbar with interactive Previous, Play/Pause, and Next buttons.
- **System Media Transport Controls (SMTC) & Tray:** Full integration with Windows media overlays, global multimedia keys, and background mini-tray mode.
- **Flexible Deployment:** Available as both a standard Windows NSIS installer and a standalone zero-install Portable executable with portable data isolation.

### 5. Obsidian & Violet Design System
- **Unified Brand Identity:** Deep obsidian dark background (`#09090B`) paired with radiant violet resonant accents (`#8B5CF6`, `#A78BFA`).
- **Signature Musical Empty States:** Custom SVG line art featuring the Acoustic Violin, Turntable Vinyl, Ultrasonic Tuning Fork, Harmonic Heart Clef, and Hourglass Metronome.
- **Dynamic Waveform Volume & Scrubber:** Interactive hover seek previews and real-time audio waveform volume sliders.

### 6. Local-First Privacy & Integrity
- **100% Telemetry Free:** No listening tracking, behavioral analytics, or cloud surveillance.
- **DPAPI Credential Encryption:** Hardware-backed Windows Data Protection API (DPAPI) encryption for any configured online provider tokens.

- **Operating System:** Windows 10 (version 1809 or later) or Windows 11 (64-bit)
- **Processor:** Dual-core 64-bit x86-64 processor (Intel Core i3 / AMD Ryzen 3 or higher recommended)
- **RAM:** 4 GB minimum (8 GB recommended for large >50,000 track libraries)
